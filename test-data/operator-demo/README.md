# Модуль пульта «Тестовые данные»

Необязательный модуль пульта оператора: кнопки **«Создать тестовые данные»** и **«Удалить тестовые данные»**
в разделе «Обслуживание». Для демонстрации платформы.

| Файл | Что это |
| --- | --- |
| `plugin.py` | Логика и API модуля (`/api/plugins/operator-demo/status`, `/create`, `/delete`), таблица `test_data_records` |
| `panel.js` | Карточка в разделе «Обслуживание» |
| `e2e_check.py` | Проверка на локальном стеке: `./scripts/e2e/run.sh test-data/operator-demo/e2e_check.py` |

**Создание:**
- вузы (1–10) с администрированием, «Людьми» и расписанием;
- в каждом вузе 4 группы, 6 преподавателей, студенты и администратор;
- у всех имена, взятые из одобренных заявок;
- занятия на две недели загружаются в фоне через импорт расписания от имени тестового администратора;
- по желанию добавляется ваш аккаунт со всеми профилями.

**Удаление:** стирается ровно то, что записано в `test_data_records`, включая данные расписания в раннерах. Настоящие вузы и люди не затрагиваются.

## Как подключается и как убрать

`scripts/deploy.sh` копирует папки `test-data/*/` с `plugin.py` в том `operator-plugins` и перезапускает пульт; пульт
загружает модули при старте. Остальное приложение от модуля не зависит.

Чтобы убрать модуль к релизу, удалите папку `test-data/operator-demo` (или весь `test-data`) и выполните
`sudo ./scripts/deploy.sh`: том очистится, кнопок в пульте не будет. Таблица `test_data_records` в базе ядра
останется пустой и ни на что не влияет; тестовые данные удалите кнопкой **до** удаления папки.
