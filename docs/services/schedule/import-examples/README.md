# Примеры файлов импорта расписания

Одна и та же таблица занятий в разных типах файлов (формат — [SPEC.md](../SPEC.md) §2.1):

- `schedule.json` — JSON;
- `schedule-1c.csv` — выгрузка 1С: Windows-1251, разделитель «;», строка шапки над заголовками;
- `schedule.xml` — XML с атрибутами.

Excel: откройте `schedule-1c.csv` в Excel и сохраните как «Книга Excel (.xlsx)» — файл загрузится так же.
Группы и преподаватели в примерах вымышленные: замените их на названия групп и ФИО участников своего вуза.
